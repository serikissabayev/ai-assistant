# Адина — движок ассистента для AI Hub

Слева аватар (Three.js, мультяшный 3D mid-poly), справа камера в «Матрице». Всё остальное — модули.

## Запуск
```bash
./start.sh 8080          # http://localhost:8080  (S — настройки, F — полный экран)
chromium --kiosk --app=http://localhost:8080   # режим киоска
```
Three.js лежит локально в `vendor/` — интернет не нужен.

**Новый Windows-компьютер:** `git clone …`, затем `aiym-engine\install_all.bat` (один раз: Whisper + Piper), потом `aiym-engine\start_all.bat`. Настройки по умолчанию (казахский язык, характер Айым, лимит 30 к/с, анализ камеры 10 к/с) уже зашиты в код — ничего настраивать не нужно.

**Windows, всё одним кликом:** `start_all.bat` (Whisper + движок + Edge). Либо только движок — двойной клик по `start.bat` (нужен Python 3 с галочкой «Add to PATH»), затем http://localhost:8080 в Chrome. Голос: `tools\install_piper.bat`.

## Структура
```
src/core/      EventBus, Config, ModuleRegistry, Engine (цикл кадра), lipsync
src/avatar/    Avatar (публичное API) + buildGirl, Eyes, Mouth, Veil, Strand (физика), textures
src/ui/        Shell (разметка, настройки, субтитры), matrix (фильтр «Матрица»)
src/modules/   manifest.json + по папке на модуль
config/engine.json   настройки для киоска (перекрываются настройками из панели)
```

## Модули
Модули — «документы», которые открывает движок: перетащите `.js` или папку в окно (или Настройки → Модули → «Открыть…»). Подробности, контракт `ctx` и пример: [docs/MODULES.md](docs/MODULES.md), [examples/greeter.js](examples/greeter.js).

## Готовые модули (в папке `modules-dist/`)
Перетащите файл в окно движка — модуль встанет и запомнится.
- **`hearing.js` — «Слух»**: стерео-микрофон, голос/тишина, направление на говорящего, распознавание речи (в браузере или на своём сервере Whisper).
- **`vision.js` — «Зрение»**: лица, кто говорит (по губам + звук), движение, жесты, ответное приветствие на взмах руки, лайк и пис в ответ на жесты. Строгость жестов 1–5 (по умолчанию 4). Копирует мимику (улыбка → улыбка, грусть → грусть, злость → злость). Если человек вытягивает вперёд-вверх прямую руку («зигует»), аватар делает шокированное лицо и не здоровается. Нужен модуль «Веб-камера». Библиотека и модели лежат в `vendor/mediapipe/` (интернет не нужен).

- **`speech.js` — «Речь»**: голос через Piper (локально на сервере), казахский/русский, губы по звуку. Установка на сервере: `./tools/install_piper.sh`, затем `./start.sh`; перетащите `speech.js` в окно. Тест: Настройки → Речь → «Сказать».

Случайные повороты головы теперь маленькие и редкие; крутой поворот — только за комаром, который изредка залетает (Настройки → Аватар → «Комар» и «Писк комара», вкл/выкл; комар — серая точка с размытыми крыльями, просто пролетает; пока он летит, она злится, после — широко улыбается ~3 с и возвращается к обычному лицу; проверка в консоли: `adina.avatar.spawnMosquito()`).

Оптимизация: Настройки → Аватар → «Качество графики» (высокое / среднее / экономное), «Лимит кадров» (по умолчанию 30), «Экономить, когда окно не в фокусе» (12 к/с, пока вы играете). «Зрение»: частота анализа (по умолчанию 10 к/с) и выбор GPU / CPU.

- **`brain.js` — «Мозг»**: разговор с языковой моделью по OpenAI-совместимому API (LM Studio `http://localhost:1235/v1`, Ollama, OpenRouter). Слушает `hearing.transcript`, отвечает потоком, озвучивает по фразам через «Речь». Если браузер блокирует запрос (CORS), идёт через прокси движка `/api/proxy`. Модель по умолчанию — `llama-3.1-kazllm-1.0-8b4`, всё меняется в панели «Мозг».

**Распознавание речи без интернета (Whisper).** В Edge встроенное распознавание часто даёт ошибку «network». Решение: `tools\install_whisper.bat`, затем `tools\start_whisper.bat` (сервер на http://localhost:8000/v1; модель `set WHISPER_MODEL=medium` для лучшего казахского). «Слух» сам переключится на него при ошибке, либо выберите «Свой сервер Whisper» в панели «Слух». Linux: `tools/install_whisper.sh`, `tools/start_whisper.sh`.

**Диагностика:** Настройки (S) → «Движок» → **Скопировать отчёт** — один текст со всем состоянием (модули и их ошибки, настройки без ключей, связь с Whisper / LLM / Piper, камера и микрофон, лог ошибок). Вставьте его в чат.

**Персонажи:** Настройки (S) → вкладка **«Аватар»** → блок **«Персонаж»** (вверху): девушка (Адина, саукеле) или парень (Адиль, шапан, тахия с пером үкі). Мимика, жесты, комар и речь у обоих одинаковые; имя по умолчанию и голос подстраиваются под выбор (своё имя не меняется).

**Язык, имена, голоса.** «Слух» по умолчанию определяет язык речи сам (казахский / русский / английский, `WHISPER_LANGS`), «Мозг» отвечает на том же языке, а «Речь» читает ответ голосом, закреплённым за персонажем: девушка — `kk_KZ-raya-x_low`, `ru_RU-irina-medium`, `en_US-lessac-medium`; парень — `kk_KZ-issai-high`, `ru_RU-denis-medium`, `en_US-ryan-medium`. Имена: девушка — Әдина (kk) / Адина (ru) / Adina (en); парень — Нұртуған / Нуртуган / Nurtogee; таблица — `src/core/Names.js`. Назвали по имени другого персонажа — он выходит и отвечает (настройка «Переключать персонажа по имени»). Поле «Имя персонажа» в настройках у каждого персонажа своё.

**Голосовые «тормоза».** «Стоп», «остановись», «хватит», «замолчи», «тоқта», «болды», “stop”, “enough” — она сразу замолкает и обрывает ответ модели (работает и пока она говорит сама; для этого «Слух» слушает короткими окнами и берёт только команды). «Не то», «не о том», «олай емес», “that's wrong” — прерывает, извиняется и спрашивает, что именно нужно. Слова: `src/core/Commands.js`.

**Автообновление модулей:** при каждом запуске движок сверяет установленные Слух / Зрение / Речь / Мозг с папкой `modules-dist/` и сам ставит версию новее (кнопку «Обновить» жать не нужно).

Клавиша **M** (или кнопка на панели камеры) включает и выключает фильтр «Матрица»: с ним камера рисуется символами, без него — обычное видео.
