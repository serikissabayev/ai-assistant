# Модули — «документы» для движка

Движок — как Word: он сам ничего не знает про слух, речь или зрение. Всё это — модули,
которые вы «открываете». Движок можно менять, не трогая модули, и наоборот.

## Как подключить модуль
1. **Перетащите** файл `.js` или папку модуля в окно движка — или нажмите
   **Настройки (S) → Модули → «Открыть файл…» / «Открыть папку…»**.
2. Модуль сразу запустится, запомнится в браузере терминала и будет работать после перезагрузки.
3. Загрузили ту же «id» ещё раз — модуль обновится; кнопка **«Откатить»** вернёт прежнюю версию.
4. **«Удалить»** — убирает модуль. Переключатель — включает/выключает без удаления.

Альтернатива для разработки: положите папку модуля в `modules/` рядом с движком — она появится сама.

## Что такое модуль
**Один файл** `.js`:
```js
export const meta = { id: 'my-module', name: 'Мой модуль', version: '1.0', engine: 1, description: '…' };
export default function create() {
  return { async start(ctx) { /* … */ }, async stop() {} };
}
```
**Или папка:** `module.json` (те же поля + `"entry": "index.js"`), `index.js` и любые ресурсы.
Внутри папки можно писать `import './helper.js'`, а файлы ресурсов получать через `ctx.asset('voice.onnx')`.

## Контракт движка (версия 1) — всё, что видит модуль
| | |
|---|---|
| `ctx.avatar` | `lookAt`, `lookAtNormalized`, `releaseLook`, `setViseme`, `setVisemes`, `setMouthOpen`, `setSpeaking`, `endSpeech`, `setEmotion`, `trigger`, `focus` |
| `ctx.bus` | `emit / on / once` — события между модулями (всё, на что подписались, снимается при выключении) |
| `ctx.config` | `get / set` — собственные настройки модуля (сохраняются) |
| `ctx.onFrame(fn)` | колбэк каждого кадра `(dt, t)` |
| `ctx.defer(fn)` | выполнить при остановке модуля |
| `ctx.ui` | `h` (создание элементов), `addPanel`, `setCaption`, `setStatus`, `toast`, `viewport.setSource(video)` |
| `ctx.asset(path)` | ссылка на файл внутри модуля |
| `ctx.libs.three` | библиотека three.js (та же, что у движка) |
| `ctx.util.lipsync` | запасной lipsync по тексту |

Модули **не импортируют внутренности движка** — только `ctx`. Пока контракт не меняется, движок
можно переписывать как угодно. При несовместимых изменениях номер контракта (`engine`) растёт,
и движок честно скажет: «Модуль написан для версии 1, а этот движок — версии 2».

## Правила хорошего модуля
- В верхнем уровне файла — только `export`, никаких действий: код запускается в `start()`.
- Камеру/микрофон открывайте в `start()` и закрывайте в `stop()`.
- Не работает один модуль — остальные продолжают работу, ошибка показывается в списке модулей.

## События для связи модулей (рекомендация)
`hearing.transcript {text, final}`, `hearing.speaker {x, y}`, `vision.person`, `vision.gesture {name}`,
`speech.say {text}`, `speech.start/end`, `brain.ask {text}`, `brain.reply {text}`.
